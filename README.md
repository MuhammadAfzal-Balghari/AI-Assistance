# AI Assistant Project

This project is an AI-powered virtual assistant built using HTML, CSS, and JavaScript. It can respond to voice commands and help you navigate websites, tell the time, and more!

## Features

<b>Voice Interaction:<b/> The assistant can recognize speech and respond accordingly.

<b>Time & Date:</b> You can ask the assistant for the current time and date.

<b>Website Navigation:</b> The assistant can open popular websites like YouTube, Google, WhatsApp, and more.

<b>Personalized Responses:</b> It responds to specific queries such as "Who are you?", "I love you", etc.

<b>Supports Speech Output:</b> The assistant speaks back to you with clear and configurable voice settings.

## Technologies Used

<b>HTML:</b> Structure of the web page.

<b>CSS:</b> Styling the interface to make it user-friendly.

<b>JavaScript:</b> The main logic and functionality, including speech recognition and synthesis.

## How It Works

<b>Speech Recognition:</b> The assistant listens for voice input via the browser using the Web Speech API.

<b>Speech Synthesis:</b> It responds with speech using the browser’s built-in speech synthesis.

<b>Voice Commands:</b> You can trigger actions by speaking specific phrases (e.g., "open YouTube", "What's the time?", "hello").

<b>Dynamic Responses:</b> Based on your input, the assistant can give dynamic responses like saying the current time, date, or even providing internet search results
